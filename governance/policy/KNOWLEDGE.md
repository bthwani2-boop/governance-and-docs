# Knowledge Policy

ARTIFACT_CLASS: DURABLE_CROSS_CUTTING_POLICY
SEMANTIC_OWNER: governance/policy/KNOWLEDGE.md
EXECUTION_AUTHORITY: NONE
IMPLEMENTATION_STATE_AUTHORITY: NONE

- Every material task classifies `GOVERNANCE_IMPACT` under `AGENTS.md`.
- New durable knowledge updates the existing correct owner when possible; learning must not mechanically create files.
- Wrong/stale/duplicate live knowledge is corrected or deleted; Git preserves history.
- Research output is distilled into BThwani invariants or discarded; research transcripts are not live governance.
- Mutable external facts are revalidated at use.
- One external reference URL is curated in one canonical reference class unless a second occurrence has a materially different purpose.
- A consuming implementation pins one exact immutable Governance commit SHA; it does not duplicate external reference lists.
- Verifiers protect relationships/invariants and must not become prose authorities.
- Future Product concepts remain absent until admitted by current need.
