# BThwani Governance and Docs

Canonical durable Governance and human development/operations guidance for BThwani.

Authority:
- governance/ = durable Product/System/architecture/policy meaning.
- docs/ = human development, release and operational guidance.
- executable implementation/configuration/runtime truth remains in consuming implementation repositories.
- execution/mutation/recovery/evidence/closure law remains in each consuming repository's Orchestrator.

Implementation repositories consume this repository only through an exact immutable commit SHA. Floating branch/tag/latest references and tracked local mirrors are not authority.

Entry points:
- governance/GOVERNANCE.md
- docs/README.md

This repository intentionally contains no Orchestrator and no live ADR or numbered lifecycle-stage tree. Git history is the archive for superseded rationale.
